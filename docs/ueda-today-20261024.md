# 「今日の上田」を、小さな入口にする

2026年10月24日。基点 main `8bd7976d604d605f87c0889260865a5de4937d15`。

## きっかけと仮説

利用者から「毎日開きたいと思えない」「地元のニュースや天気が本人にも家族にも分かれば」という声があった。生活に関係する情報を見るついでに家族の記録に目が向く、という仮説を小さく試す。毎日開く効果や継続率の改善はまだ測っていない。

- 本人：日付→本人の今日→今日の予定、という順を守り、その後に「今日の上田」。挨拶・お薬・日付と和暦・今までの読み上げは残す。
- 家族：ホームの上に同じ上田の情報。家族の現在地の天気だとは表示しない。
- 最初は今日の予報と発表時刻だけ。押すと明日の予報、任意の読み上げ、地域の話題が開く。読み上げも返信も自動では行わない。
- ごみ出しの案内は既存の「上田の暮らしサポート」に置き、ホームに別の一覧を増やさない。

## 実装範囲

`ueda-today.js` / `.css` を2つのホームに置く。家庭の記録、認証、権限、LINE送信には触れない。公開情報の取得はホームが表示された時に始め、画面内では30分間共用する。個人情報・家庭の番号・位置情報を送らず、Cookieと参照元も送らない。気象庁への通常の通信でIP等が伝わることは privacy.html に追記。

### 天気

- [気象庁の長野県中部の予報](https://www.jma.go.jp/bosai/forecast/#area_type=class10s&area_code=200020)の予報文をそのまま抜き出す。独自の予報や健康への助言は作らない。
- 公開JSON `https://www.jma.go.jp/bosai/forecast/data/forecast/200000.json` のうち地域コード `200020`。2026-10-24取得でHTTP 200、CORS `*` を確認。
- [気象庁の地域定義](https://www.jma.go.jp/bosai/common/const/area.json)で「上田市→上田地域→長野県中部」を確認した。上田市の地点予報ではない。松本等の代表地点の気温を上田市の気温として出さない。
- [気象庁の利用条件](https://www.jma.go.jp/jma/kishou/info/coment.html)に合わせ、出典と抜き出した表示であることを記載。
- 日本時間で今日・明日を選ぶ。発表から18時間超、未来の発表、対象地域や当日の予報がない場合は表示しない。8秒の取得打ち切り、通信失敗時の短い案内と公式ページへのリンクを用意する。失敗を古い情報で隠さない。予報を端末や共有サーバーへ永続保存しない。
- 公開JSONの形式・配信が今後も同じである保証はない。形が変わった時は「確認できません」と公式案内を出し、通常の記録操作を妨げない。

### 地域の話題

- 今回は**自動ニュース配信ではなく、公式案内を人が確認した期限付きの紹介**。最大2件、事実だけの短い表題・開催日・確認日・公式リンクを掲載する。記事本文や写真は転載しない。
- 初回の根拠：[武石「秋色フェス」](https://www.city.ueda.nagano.jp/soshiki/ttiiki/138185.html)（11月8日10〜15時）、[うえだ城下町映画祭](https://www.city.ueda.nagano.jp/site/30-uedacastletownff/)（11月21・22日）。2026-10-24確認。
- 開催終了と確認から7日の早い方で表から下げる。新しい情報がない時は「掲載できる話題はありません」と市の催しカレンダーを案内する。「催しがない」とは扱わない。
- 確認日は本当に公式案内を再確認した時だけ更新する。日付だけの自動更新は禁止。開催変更・中止の即時反映は未対応なので、参加前は公式案内で確かめられる文言にする。
- 市のRSS `https://www.city.ueda.nagano.jp/rss/10/list10.xml` は今回CORS許可なし。勝手な外部中継サービスや新しい定期処理を追加していない。[市のリンク・著作権の案内](https://www.city.ueda.nagano.jp/soshiki/uedapr/132245.html)も確認。今後の自動取り込みは利用条件・取得方法・終了日／中止の扱い・運営負担を確認して別途判断する。
- 上田市や気象庁との提携を意味しない。

## 確認方法と未確認

- 基本検査。`node tests/ueda-today.test.mjs`：地域抽出、日本時間の日替わり、古い／未来／欠損データ、終了・7日期限、重複・2件上限、外部リンクの範囲、HTMLを実行しない表示、入口で取得しない、任意の音声、通信失敗、同時取得を重ねないこと。
- 既存CIの `tests/ueda-support.test.mjs` から同検査も実行する。本人UI・ホームDOM・ホーム回帰・既存音声の関連検査も実行。
- 通信と個人データを切り離したHTMLでChromium表示確認：320 / 390 / 1024px、本人・家族とも開閉時の横はみ出しなし。ボタン高さ48px以上。予報は検査用固定データ、実ユーザーのデータは使用しない。これはiPhone/Android実機・実際の音声品質の確認とは区別する。
- 手元の端末で確かめること：予報と自分の予定を取り違えないか、元の挨拶・お薬が探しにくくならないか、戻ってきた時の鮮度、音量・止める操作。LINE内ブラウザーも未確認。
- まず本人・家族に「何を見に開いたか」「役に立ったか」「邪魔だったか」を確認する。毎日の起動回数だけを価値や健康の改善と見なさない。
