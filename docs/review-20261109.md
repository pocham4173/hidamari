# 11月9日：タグの前の記録と、いま選んだ状況を分ける

単一のAIが10の役割から検討した。実在の10人の評価や利用者調査ではない。基準はPR #241 f4c418de11efbe062469dd6b33a53c7f48cc76c0。main 80813fb、#240は28b5476。両PRは未マージ。前回の起動画面修正の基本CI [42460635577](https://github.com/pocham4173/hidamari/actions/runs/42460635577) は成功。実機の起動秒数の証拠ではない。

**観察 → なぜ → 原因 → 改善 → 検査**：架空のタグで「道に迷っているようです」を保存し、別の状況を選ぶと旧成功文が残った。10分以内に送信を押すと書込みは1件のままなのに成功色の「記録済み」。今回の選択まで家族に伝わったと思われる可能性は仮説。成功表示が選び直しで消えず、再送を抑えた分岐でも成功として表示するのが原因。選び直しで前の成功表示を消し、再送を抑えたら「今回は記録していません」と表示する。元の時間制限と、急ぐときの電話の入口を保つ。

|視点|根拠・困りごとと判断|
|---|---|
|本人の自律|状況は発見者が選ぶ。本人の無事の証明にはせず、本人へ声をかける案内を保つ。|
|離れて暮らす家族|短時間では2件目が書かれない。家族が知り得る情報と表示をそろえる。|
|忙しい家族|選択のたびに通知する案は負担。選ぶだけでは送らない。|
|読みやすさ|前回の緑の成功表示が残っていた。色に頼らず「今回は記録していません」と伝える。|
|画面設計|選択中と保存後が混ざる。以前の結果を消し、常設の説明は増やさない。|
|通信|状況が変われば制限を外す案は連打・重複を招く。既存の10分を維持し、待たずに電話できる案内を残す。|
|プライバシー|前回の状況を端末に追加保存する必要はない。記録内容・保存先・送信先は変更しない。|
|信頼性|書込み件数だけでは見落としていた。選び直し直後の表示、再送時の文・成功色、時間経過後の記録を検査。|
|上田の地域生活|市のシールにはメールと発見者との連絡手段がある。まいにこの一方向の記録を会話に見せない。[市公式](https://www.city.ueda.nagano.jp/soshiki/korei/2692.html)（11月9日確認）。|
|個人運営|毎秒のカウントダウンや新しい通知は負担が増える。今回は画面の状態表示だけ直す。地域の話題の7日制限は伸ばさず公式リンクを維持。|
