## 保存と削除

- `consents/{uid}` は当該利用者だけが取得・保存・削除できる。一覧検索は不可。
- 撤回後は共有記録の読取・新規保存と家族通知の取得を拒否。同一batchでの撤回＋新規保存も拒否する。
- 同意がなくても退会・タグ停止・管理者による世帯削除・アカウント削除は可能。
- 同意はアカウント単位。世帯削除だけでは各アカウントの同意を削除しない。アカウント削除はAuth削除前に同意を削除する。
- 家族が入力する場合のチェックは「本人へ説明して同意を確認した」という申告であり、アプリが本人の意思や代理権を認定するものではない。
- 自分の同意撤回だけで他の家族の同意や既存の共有記録が消えるわけではない。この違いを画面に明記。

## 公開手順

1. PRの基本検査とFirebaseルール検査を通す。
2. Firebaseプロジェクト `hidamari-5f8de` の現在のルールを控え、本PRの `firestore.rules` を公開する。
3. PRをmainへマージし、GitHub Pagesの反映を確認する。ルール公開から画面反映までの間、旧画面では共有記録を利用できなくなるため、この2操作は続けて実施する。
4. 公開ページで新スクリプト・ポリシー・免責・未選択の同意欄を確認する。開いたままの利用者はページを再読み込みする。
5. 画面公開が失敗した場合は控えたルールへ戻し、旧画面との互換性を回復してから原因を調べる。ルール更新に入れない場合、先に画面だけを公開しない。
