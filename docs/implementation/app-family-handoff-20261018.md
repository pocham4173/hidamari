# 本人の挨拶と、お願いの往復を普段の画面へ

2026年10月18日。基準 main: `b60e8f31454aec0617aec0a18f07473ed635a981`（PR #210）。「実装して」の指示に基づき、独立試作で確認した操作を既存の本番アプリへ組み込む。

## 今回の範囲

- 日付の下に「本人の今日」と名前入りの大きな挨拶。名前は現在の登録名から表示し、試作の架空人物は使わない。押すと声を聞け、記録は別の挨拶ボタンから保存する。音声停止、令和・昭和・平成・西暦、任意の体調、朝昼夜のお薬を維持。音声の説明は記録の下へ移す。
- 日付は淡い橙と濃い文字へ。もとの橙・緑・青・紫と既存機能を保つ。
- 本人のお願いごとに、家族の名前・日時・返事・対応予定・対応した報告を表示。本人側にも同じお願いと返事を並べ、声でも確認できる。自由返信、対応予定の取り消し、対応報告の訂正を用意。「そっとしておいて」は気持ちを確認する返事に限る。
- 家族が複数対応を申し出た場合は全員を表示し、分担は本人同士で相談する。先着1人の排他的な担当確定ではない。
- 一人で残した記録も、後から承認された家族に共有されることを説明する。通信未確認と家族不在を、送信成功とは表示しない。

## 保存と共有

新しい保存先・購読・通知は追加しない。既存の `groups/{gid}/events` に `onegai-back` を追加する。`replyTo` は元の `onegai` のID。`requestStage` は表示用の `planned / done / noted / withdrawn / reply`。旧版も返事の本文は読める。

自由返信は対応予定を自動変更しない。予定・完了・訂正は明示的な操作で記録する。元のお願いは書き換えず、訂正も新しい返事として残す。保存成功は相手の受信・既読や実際の対応を証明しない。

返信前に元のお願いをサーバーから読み直す。現在の家庭・アカウント・画面・通信確認を照合し、元のお願いの削除や内容変更が分かった場合は送信しない。保存待ちの間の二重押しを止め、古い家庭の完了表示を新しい画面へ出さない。同一アカウントの別端末から同時に操作した場合の全体での重複排除や、排他的な引受けは提供しない。

最近100件のイベントの範囲でお願いを表示する。古いお願いがこの範囲から外れれば、一覧に残らない。全期間の未対応件数・期限管理としては使わず、過去は既存の履歴で確認する。家族の「電話で話しました」は本人へ伝える報告であり、電話の観察項目・相談資料は自動作成しない。詳しい様子は既存の「様子を記録する」を使う。

Firestore Rules、認証、復旧、承認条件、LINEの送信役、実利用者のデータには変更を加えない。本番の新規保存は利用者が通常の操作を行ったときだけ。開いたPR #193等の別変更は取り込まない。
