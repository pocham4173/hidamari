# 本人の毎日の操作・家族の返事・上田のごみ出し（2026-10-18）

基準 main 7ab0d0a。収益性を除いた暫定評価72/100に基づく3点に限定した改善。以前の68点とは配点が違うため比較しない。今回のコード変更だけで点数や実測の成果は増やさない。

## 変更

1. 本人ホームの日付の上下余白と挨拶カードの余白を減らした。日付・時刻・名前の文字サイズは維持。西暦を独立した行に固定せず、和暦・六曜とともに幅に合わせて折り返す。挨拶の共有に関する説明は、記録ボタンの下に移した。年号、音声、挨拶・薬・任意の体調、共有の説明は削除していない。
2. 閉じた「お願い・家族とのやりとり」に、本人自身の表示中のお願いへの最新の返事の日時・家族名を表示。返事なし、最新確認不能を区別。未読・既読とは呼ばない。元のお願いが消えた場合や家庭切替では表示を消す。保存・権限・通知の処理は変更しない。対象は既存の最近100件の読み込み範囲に限る。
3. 暮らしサポートの「家のこと・ごみ出し」と該当検索に、地区を選ぶ→公式カレンダー→自治会番号と日付→変更情報の順の案内を追加。住所は取得・保存しない。地区選択だけで外部を開かず、表示されたリンクを本人が押す。2027年以降は2026年版の地区選択を無効にし、市の最新一覧へ案内する。
