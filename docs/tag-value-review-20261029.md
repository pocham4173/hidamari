# 上田市の見守りシールと、まいにこのタグを使い分ける

確認日：2026年10月29日。単一AIによる10役割の検討であり、実在の利用者・市職員・救急隊員への聞き取りや独立審査ではない。

## 結論

**市の制度を利用できる方には、その制度を案内する。まいにこは普段の家族の記録と、本人が望む手助けを伝える備えを補う。** 似たQRを作っただけで市より優れているとは言わない。行政との提携・連携・捜索・救助・通知到達を約束しない。

「迷子タグ」は現行画面の「おまもりタグ」、「緊急タグ」は「災害用QR／災害・緊急時支援カード」と解釈した。二つは用途も公開する情報も異なる。

## 強みと、まだ弱い点

- **おまもりタグの強み**：普段使う家族画面へ状況を残し、家族の記録の流れで見返せる。発見者は氏名・電話を入力しない。管理者による停止経路がある。これらの使いやすさ・発見率向上は未実測。「個人情報を直接見せない」は市の旧資料にもあり独自性とは言わない。
- **おまもりタグの弱み**：どこにいるか、誰と連絡すればよいかを家族に伝えられない。記録・LINE通知だけでは保護・引渡しは完結しない。市のシールを置き換える提案はしない。
- **緊急時支援カードの強み**：必要な手助けを本人の言葉で選べる。紙の文字とQRの両方で伝わり、本人のスマホ操作が不要。家族が返事をしない日にも備えとして役立つ可能性がある。
- **緊急時支援カードの弱み**：印刷内容が古くなる。紛失・撮影済みコピーは消せない。日付と同意の確認、連絡先変更時の差替えが必要。服薬の証明・最新の医療情報ではない。

## 10視点の議論と採否

| 役割 | 根拠・問題 | 採用／見送り |
| --- | --- | --- |
| 本人の自律・尊厳 | 認知症や年齢だけで本人の希望を決められない | おまもりという現名称と、本人が手助けを選ぶ仕組みを維持。強制携帯・自動追跡を足さない |
| 離れて暮らす家族 | 状況だけでは迎えに行く場所が分からない | 市の仕組みと一方向記録の違いを明示。位置共有は本人・発見者の同意と安全設計が必要なので今回は見送り |
| 忙しい家族 | 独立した監視画面を増やすと負担になりうる（仮説） | 普段の家族画面を使う。返信義務・新しい確認ボタンは増やさない |
| アクセシビリティ | QR読取に対応していない人・端末もある | 保存済みの緊急時カードはQR部品なしでも文字を印刷できるよう改善 |
| UI/UX | 市・おまもり・災害QRの違いが初見では分かりづらい | 安心のタグ画面に閉じた使い分け案内。ホームに比較説明を並べない |
| 性能・通信 | SDK不調、端末保存不可、送信待ちで困る | 送信中の多重操作を抑止。端末保存失敗とサーバー記録失敗を区別。通信部品不調時に案内 |
| セキュリティ | 紙カードは誰でも読める。公開タグは匿名投稿経路 | 同意・保存項目・既存ルールを維持。公開情報・送信先を増やさない。UI抑止をサーバー側の不正防止とは称さない |
| 検査・信頼性 | 状況を変更すると送信中でも再送できた | 模擬サーバーで修正前失敗を確認。停止・エラー・再試行・保存不可を検査 |
| 上田の地域生活 | 市には連絡できる制度が既にある | 市公式案内への導線を追加。市の登録とまいにこの登録が連動するとは書かない |
| 個人運営・価値 | 即応窓口や新しい通信経路には運営責任が増す | 今回は既存の記録と紙カードを堅くする。24時間対応・チャット・有料オプションを約束しない |

## ビコーズマップ

1. **観察**：送信待ちに選択を変えて押すと模擬サーバーへ2回書き込む。**原因**：選択変更が送信ボタンを有効化し、処理中のガードがない。**仮説**：現場で再送・混乱を招く。**改善**：送信中は選択をロックし、処理中フラグでも防ぐ。**確認**：修正前2回／修正後1回。
2. **観察**：端末保存へのアクセスが送信前に失敗しうる。保存成功後の端末保存失敗も送信失敗に扱う。**原因**：端末キャッシュとサーバー保存の成功状態を分けていない。**改善**：端末保存を補助として扱い、同一ページ内の再送抑止を残す。**確認**：保存禁止環境でも成功・再送抑止・通信失敗後の再試行を模擬。再読込や別端末の制限は既存サーバールールによる。
3. **観察**：既存の支援カードは文字を印刷できる構成なのに、QR部品不調時は印刷入口自体が出ない。**原因**：QR表示と印刷が必須依存。**改善**：双方同意済み・保存済みの内容を文字カードで印刷。**確認**：部品なし・生成失敗・通常のQR付き・旧同意は印刷不可・入力のHTML無害化を検査。

反対意見：文字だけではQRの利便性を失う。ただし紙の情報は読めるため、備えを全く取り出せないより有用。新規カードは従来どおりQR作成と保存が成功したときだけ保存する。今回は同意未確認の入力から紙を作る抜け道を作らない。

## 次の判断に必要な3点

1. QRから状況を記録した後、発見者と家族がどう安全に連絡するか。市の制度との使い分けを優先し、まいにこの即応能力を誇張しない。
