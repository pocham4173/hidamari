## 今回の範囲

- 本人の今日：元のまいにこの配色、令和・昭和・平成・西暦を併記した日付、予定・家族の連絡・操作結果の読み上げ、音のオン／オフ、おはよう、朝・昼・夜のお薬の記録、家族への返事・電話のお願い、取り消し。
- 家族の次の行動：最後の電話・訪問、確認したことを選んだ電話記録、担当メモと実際の引受け、引受けと完了の区別、それぞれの取り消し。
- 相談の1枚：見せる記録と相談したいことを明示的に選び、記録者・日時つきで確認して印刷。選んでいない内容を載せない。

操作は同じページのメモリー内だけで連動する。本番アカウント、Firebase、LINE、通知、端末の記録保存には接続しない。自由入力欄を置かず、用意した例だけを選ぶ。再読み込みで初期状態へ戻る。外部への記録送信を禁止するページ専用CSPを設定し、第三者スクリプト・解析・フォントの取得は行わない。既存のアプリや本番の設定は変更しない。

試作を公開しても、本番アプリへの機能導入や権限管理の完成を意味しない。画面整理と手順を確認するためのページである。

## 画面整理でも残すこと

利用者からの2026年10月18日の指示を、今後の設計でも維持する。

- 読み上げを、予定だけの機能へ狭めない。日付・時刻、家族からの連絡、本人が押した結果を声でも確認し、音を消す選択と文字での確認を残す。この試作では開いた直後の自動発声は行わず、本人の操作後だけ読む。
- `index.html` の色を基準にする。本人の橙 `#F28A42`、記録の緑 `#63A57D`、予定の青 `#4F7FD3`、相談の紫、家族の青緑。淡い背景や濃い文字も元のパレットから使う。
- 和暦は元の表示どおり、2026年を「令和8年（昭和101年・平成38年）」と併記する。これは昭和・平成をそのまま数えた換算表示。固定の試作日時であることを画面・音声とも明示する。
- 「おはよう」と「薬を飲んだ」は本人が残す大切な記録。家族の電話・訪問と混ぜず、記録者と日時を残す。服薬の実施や安否を証明する表示にしない。家族が見た／対応したとも扱わない。
- 相談メモには本人の記録も選べるが、自動で選択しない。本人の記録を取り消したら選択・古い印刷プレビューからも外す。家族の最後の電話・訪問は上書きしない。

家族画面には既存の「上田の暮らしサポート」への入口を置き、ごみのカレンダー・変更のお知らせ・「さんあ～る」はそのページ内にまとめた。社協の有償支援も同じページで探せる。[地域との接続案](../ueda-daily-life-20261018.md)に、確認済みの情報と未実装の連携を分けて記録した。自動取り込み・通知・自治体との提携は行っていない。

この試作には同期・ログイン・権限管理がないため、本番の認証・復旧・家族間のデータ保護・LINE安全性を検証したことにはならない。

## 検査の再現

既存CIで使用している `jsdom@26.1.0` が必要。実際の利用者情報は使わない。

```sh
node --test tests/prototype-family-flow.test.mjs
node .github/scripts/check-basics.mjs
```

ブラウザーでは次を確認する。

1. 「ありがとう」を押し、「家族の画面で確かめる」で返事が見える。既読にはならない。
2. 「私が引き受ける」を押しても完了にならない。「できたことを記録」で完了し、取り消せる。
3. 「電話を記録する」で確認項目を選ぶ。保存した電話が最後の連絡になり、取り消すと元に戻る。
4. 「相談に使う記録を選ぶ」で記録・相談内容をそれぞれ選ぶ。選択を変えると古い印刷プレビューが閉じる。
5. 本人の「おはよう」と朝・昼・夜の服薬を押し、家族画面に本人名と日時つきで表示される。最後の電話・訪問の日付は変わらない。相談に選んでから取り消すと古いプレビューが閉じる。
6. 日付・予定・家族の連絡の音声を試し、「声のお返事」をオフにすると操作結果は読まない。「聞く」ボタンはオフでも本人が選んだ内容だけ読む。
7. 「試作を最初に戻す」は確認後に例だけを初期化する。再読み込みでも初期状態になる。

## 次の判断に使うこと

本人には「予定を見つける・返事をする・間違いを戻す」、家族には「最後の連絡・引受けた人・未完了を見つける」を試してもらう準備とする。所要時間だけでなく、助言が必要だった場面・誤操作・本人の希望を記録する。実測結果はまだない。
