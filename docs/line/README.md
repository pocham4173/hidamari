## 友だち追加のあいさつ

送信役（Cloudflare Worker の `worker.js`）が、友だち追加のときに返事で送る（`MSG_WELCOME`）。
管理画面の「あいさつメッセージ」はオフにする（オンのままだと、あいさつが2通届く）。

```
まいにこへようこそ🌼

今日の様子と予定を、家族でひとつに。
できる日は本人が、難しい日は家族が使えます。

下の『まいにこを開く』から始めてください。

予定のお知らせをLINEで受け取るには、まいにこでLINE連携の設定が必要です。友だち追加だけでは設定は完了しません。

ご家族から招待リンクが届いている方は、そのリンクから進んでください。
```

## 既存の利用者が迷わないために（アプリ側で対応済み）

- メニューから開くと、いつものブラウザーで開く。Androidでホーム画面のアイコンを使っている人は、同じ記録が開く
- iPhoneでホーム画面のアイコンを使っている人は、Safariとホーム画面のアイコンで保存場所が別のため、Safariでは入口が出る。入口には「すでに使っている方へ：ホーム画面の『まいにこ』から開いてください。ホーム画面に置いていないときや、記録が見つからないときは、新しく始めずに、下の『使っていた記録に戻る』を押してください」と出る
- iPhoneのSafariで「はじめて使う」を押すと、先に「ホーム画面に『まいにこ』のアイコンがある方は、ここで始めずに、アイコンから開いてください」と確認が出る。「アイコンがある」を選ぶと、新しい家庭は作らず「Safariを閉じて、ホーム画面の『まいにこ』アイコンを押してください」とだけ出る（2026-10-11）
- iPhoneのSafariで「使っていた記録に戻る」を押すと、一番上に「このiPhoneのホーム画面に『まいにこ』アイコンがある方：Safariを閉じて、アイコンから開いてください」が出る。その下に、メールとパスワードで同じアカウントに戻る方法がある
- iPhoneのSafariで家庭が開いたときは、画面の上に固定して「Safariで開いています（アイコンとは保存場所が別）。下の『つながっている人』がいつもと違えば、アイコンから開いてください」と出る。保存場所が別なことは確かだが、同じ家庭かどうかはアプリから確かめられない（メールとパスワードで戻った場合は同じ家庭）ため、「別の記録」とは言い切らず、「つながっている人」で見比べてもらう。Safariだけで使う人は「このSafariで使う」を押すと、次から出ない
- 制約：LINEのメニューやSafariから、iPhoneのホーム画面のアイコン(ホーム画面に追加したまいにこ)を直接開くことはできない（iPhoneの仕組み）。そのため、アイコンで使っている人に「アイコンから開く」と案内する
- LINEの中で開いてしまったときは、「まず、いつものブラウザーで開いてください」と、Chrome／いつものブラウザーで開くボタンが出る
- 友だち追加は、まいにこへの登録・家族への参加・LINE連携の完了として扱わない。LINE連携は、まいにこの「LINEで予定のお知らせ」→「自分のLINEをつなぐ」で行う
- アプリの「自分のLINE」には、状態を実際の記録で出す：まだつながっていません → ⏳ 確認中（コードを作った・LINEでの送信待ち）→ ✓ 登録済み。送る前に「つながったか確かめる」を押すと「まだ」と出し、コードの有効期限（10分）が過ぎたら「つなげませんでした」と作り直し方を出す。LINEを開いただけでは「登録済み」にしない
